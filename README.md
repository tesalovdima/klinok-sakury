# Клинок Сакуры

Аниме idle-RPG для браузера: автобой, боссы, снаряжение с грейдами и заточкой в духе Lineage 2, грань предметов, питомцы, арена, башня испытаний, подземелья, пробуждение с вечным древом, сюжетные главы, пропуск сезона и процедурная музыка. Без библиотек — только canvas, DOM и Web Audio.

## Что нового в 3.0

- **Пробуждение (престиж).** С 50-го этапа можно переродиться: этап, уровень и тренировка сбрасываются, а снаряжение, питомцы, самоцветы и кристаллы остаются. За перерождение дают лепестки сакуры — вечную валюту древа из 11 узлов (атака, здоровье, золото, опыт, шанс заточки, стартовый этап, офлайн-доход и другие).
- **Башня сакуры.** 120 ярусов с отдельными стражами, недельной наградой и авто-подъёмом. За каждый 10-й ярус — лепестки и билеты призыва.
- **Подземелья дня.** Четыре подземелья на золото, свитки, кристаллы и опыт. Три ключа в день, дополнительные — за рекламу и самоцветы.
- **Грань предметов.** У вещей от грейда D есть случайные свойства, которые перековываются за кристаллы. Одна и та же вещь грейда может быть заметно лучше другой.
- **Сюжетные главы.** 13 последовательных глав ведут игрока от первого удара до бесконечного пути и выдают награды за прогресс.
- **Коллекция снаряжения.** Каждая купленная вещь каждого грейда навсегда даёт +0,2% атаки и здоровья (до +12,6%).
- **Фонд сакуры.** Разовая покупка, которая возвращает самоцветы за уровни, и удвоение первой покупки самоцветов.
- **Мягкая стена босса.** Поражение больше не останавливает автобой: герой фармит этап и сам возвращается к боссу, пауза между попытками растёт.
- **Заточка добрее.** До +7 неудача откатывает к +3 вместо разрушения; разрушение начинается с +8. Каждая неудача даёт «искру» +6% к следующей попытке, благословенные свитки по-прежнему спасают вещь.
- **Локальные шрифты.** Russo One и M PLUS Rounded 1c лежат в репозитории (SIL OFL), поэтому на Яндекс Играх нет внешних запросов и не нужна ручная загрузка шрифтов.

## Запуск локально

Нужен [Node.js](https://nodejs.org/) 18 или новее.

```bash
git clone https://github.com/tesalovdima/klinok-sakury
cd klinok-sakury
node build.js
```

Сборка создаёт две версии:

- `dist/yandex/index.html` — полная страница вместе с локальными шрифтами. Её удобно открывать локально.
- `dist/klinok-sakury.html` — версия для артефакта Claude. Это фрагмент без `<html>`/`<head>`, напрямую в браузере он не откроется.

Запустите локальный сервер и откройте игру:

```bash
npx serve dist/yandex
# или
python3 -m http.server 8080 --directory dist/yandex
```

Затем откройте в браузере `http://localhost:8080` (у `npx serve` порт по умолчанию 3000).

Сервер нужен потому, что страница подключает `/sdk.js`. Вне Яндекс Игр SDK не загрузится, и игра сама включит тестовый режим: реклама и покупки там демонстрационные, деньги не списываются. Ошибка 404 на `/sdk.js` в консоли — это нормально.

Прогресс хранится в `localStorage` браузера под ключом `klinok-sakury-v1`. Чтобы начать заново, нажмите «Начать игру заново» в настройках или очистите данные сайта. Старые сохранения (v3) переводятся в v4 без потери прогресса: предметы получают грань, а башня, подземелья и древо добавляются пустыми.

## Структура

| Путь | Что внутри |
|---|---|
| `src/balance.js` | Баланс: грейды, предметы, грань, монстры, пробуждение, башня, подземелья, питомцы, арена, задания, магазин |
| `src/art*.js` | Отрисовка героя, грейдов, монстров, боссов, питомцев, иконок |
| `src/audio.js` | Музыка и звуковые эффекты |
| `src/platform.js` | Адаптер Яндекс Игр (реклама, покупки, облако, безопасное хранилище) и тестовый режим |
| `src/game/*.js` | Логика игры, склеивается в один скрипт по порядку номеров |
| `src/game/15_systems.js` | Пробуждение, башня, подземелья, главы, фонд, перековка |
| `src/game/35_trials.js` | Панели испытаний и дуэльный бой |
| `src/shell.html`, `src/style.css` | Разметка и стили |
| `build.js` | Сборка в `dist/` |
| `sim.js` | Симуляция прогрессии для подбора баланса: `node sim.js 8` (часов), второй аргумент — порог пробуждения |
| `dist/README_YANDEX.md` | Как опубликовать на Яндекс Играх |

После правок в `src/` снова запустите `node build.js` и обновите страницу.

## Баланс

`node sim.js 8` моделирует восемь часов игры: покупки, заточку с искрой, грань, пробуждение и подъём по башне. Смотрите, на каком часу игрок упирается в стену, сколько раз пробуждается и до какого яруса доходит. Поломки заточки и «искра» тоже учитываются.

## Шрифты

В `fonts/` лежат `woff2`-подмножества Russo One и M PLUS Rounded 1c (кириллица и латиница, SIL OFL). `fonts/fonts.css` собирается скриптом и копируется в `dist/yandex/fonts` вместе со всеми файлами. Менять шрифты можно, отредактировав `fonts/fonts.css`.
