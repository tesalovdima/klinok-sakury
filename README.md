# Клинок Сакуры

Аниме idle-RPG для браузера: автобой, боссы, снаряжение и заточка в духе Lineage 2, питомцы, арена, задания, пропуск сезона, процедурная музыка. Без библиотек, только canvas, DOM и Web Audio.

## Запуск локально

Нужен [Node.js](https://nodejs.org/) 18 или новее.

```bash
git clone https://github.com/tesalovdima/klinok-sakury
cd klinok-sakury
node build.js
```

Сборка создаёт две версии:

- `dist/yandex/index.html` — полная страница. Её удобно открывать локально.
- `dist/klinok-sakury.html` — версия для артефакта Claude. Это фрагмент без `<html>`/`<head>`, напрямую в браузере он не откроется.

Запустите локальный сервер и откройте игру:

```bash
npx serve dist/yandex
# или
python3 -m http.server 8080 --directory dist/yandex
```

Затем откройте в браузере `http://localhost:8080` (у `npx serve` порт по умолчанию 3000).

Сервер нужен потому, что страница подключает `fonts/fonts.css` и `/sdk.js`. Вне Яндекс Игр SDK не загрузится, и игра сама включит тестовый режим: реклама и покупки там демонстрационные, деньги не списываются. Ошибка 404 на `/sdk.js` в консоли — это нормально.

Прогресс хранится в `localStorage` браузера под ключом `klinok-sakury-v1`. Чтобы начать заново, нажмите «Начать игру заново» в настройках или очистите данные сайта.

## Шрифты

Скачайте семейства Russo One и M PLUS Rounded 1c с fonts.google.com и положите файлы `.ttf` в `fonts/` под именами из `fonts/fonts.css`. Без них игра использует системные шрифты.

## Структура

| Путь | Что внутри |
|---|---|
| `src/balance.js` | Баланс: грейды, предметы, монстры, питомцы, арена, задания, магазин |
| `src/art*.js` | Отрисовка героя, грейдов, монстров, боссов, питомцев, иконок |
| `src/audio.js` | Музыка и звуковые эффекты |
| `src/platform.js` | Адаптер Яндекс Игр (реклама, покупки, облако) и тестовый режим |
| `src/game/*.js` | Логика игры, склеивается в один скрипт по порядку номеров |
| `src/shell.html`, `src/style.css` | Разметка и стили |
| `build.js` | Сборка в `dist/` |
| `sim.js` | Симуляция прогрессии для подбора баланса: `node sim.js 8` (часов игры) |
| `dist/README_YANDEX.md` | Как опубликовать на Яндекс Играх |

После правок в `src/` снова запустите `node build.js` и обновите страницу.
